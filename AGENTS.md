# TrustNest repository instructions

TrustNest is an Ireland-focused community platform. The default branch is `main` and the remote is `https://github.com/sumitbolla7/TrustNest.git`.

- Follow the active phase and get the maintainer’s approval before starting Phase 1.
- Work inside this repository. Keep the original source folder and production systems outside the work.
- Use an isolated development database and synthetic data. Keep service credentials local and review browser-visible configuration for appropriate restrictions.
- Preserve upstream copyright, licence and attribution. Record inherited functionality, current changes and future work accurately.
- Review modified and staged files, run appropriate validation and scan for sensitive data. Update README.md and PROGRESS.md when relevant.
- Create descriptive commits for meaningful changes and push promptly using an ordinary Git push. Preserve commit timestamps and shared branch history.
- Document validation results and unresolved concerns in PROGRESS.md. Use SECURITY.md for vulnerability reports.
